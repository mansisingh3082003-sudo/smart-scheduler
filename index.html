Smart Scheduler Booking System • Real-Life Based Web Application

1. Project Synopsis

Smart Scheduler Booking System is a full-featured web application designed to solve common scheduling bottlenecks in appointment-based businesses. It eliminates double-bookings through dynamic conflict verification, reduces client no-shows via automated notification invites, and empowers service providers with an intuitive administrative dashboard.

Key Objectives

  • Zero double-booking via transactional slot locking.
  • Dynamic availability calculation based on working hours, lunch breaks, and buffers.
  • Self-service booking, rescheduling, and cancellation with instant feedback.
  • Comprehensive administrator analytics on revenue, utilization, and cancellations.

Technical Stack

  • Frontend: HTML5, Tailwind CSS, JavaScript (ES6+ Modules).
  • State & Concurrency: Reactive LocalStorage State Engine with ACID validation checks.
  • Audio & Media: Native Web Audio API Synthesizer (Zero asset latency).
  • Backend Option: Node.js / Express REST API with SQLite/PostgreSQL schema.

2. College Viva Presentation Checklist

Q1: How does the system prevent two users from booking the same slot simultaneously?

Answer: Before confirming a reservation, the system executes an atomic check (isSlotBooked()) validating that the chosen date, time slot, and service do not have an active (Confirmed or Rescheduled) record. In the database architecture, this is backed by a composite unique constraint: UNIQUE (service_id, booking_date, start_time).

Q2: How are time slots generated dynamically?

Answer: The Calendar Engine takes the provider's operating hours (e.g. 09:00 to 18:00), subtracts lunch breaks (13:00 to 14:00), and partitions the remaining time into discrete intervals equal to Service Duration + Buffer Time. It then checks each interval against existing bookings and past elapsed times.

Q3: How does cancellation and rescheduling handle slot availability?

Answer: When an appointment is cancelled, its status updates to 'Cancelled', immediately freeing up that time slot on the live calendar for other clients. Rescheduling checks the new chosen slot for availability, updates the appointment record, and marks it as rescheduled.
